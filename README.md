# darkarena1.github.io

Serves one file for TimeTug: `/timetug/appcast.xml`.

Copies of TimeTug released before the move to Binary Companion check for updates at
`https://darkarena1.github.io/timetug/appcast.xml`. GitHub does not redirect Pages URLs when a repository is
transferred, so this repository keeps that address alive. A scheduled workflow copies the live feed from
`https://timetug.binarycompanion.com/appcast.xml` into `timetug/appcast.xml` whenever it changes.

Keep this repository. Deleting it would stop updates for any installed copy that has not yet updated.
